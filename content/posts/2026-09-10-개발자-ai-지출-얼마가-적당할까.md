## 먼저 실제 가격표

공식 페이지 기준입니다.

| 도구 | 개인 플랜 | 상위 플랜 |
|---|---|---|
| Claude Pro | 월 $20 (연간 시 월 $17) | Max 월 $100부터 |
| Cursor | Individual 월 $20 | Teams 사용자당 월 $40 |

여기에 API를 직접 쓴다면 사용량만큼 더 붙습니다 (Claude Opus 5 기준 100만 토큰당 입력 $5 / 출력 $25).

흔한 조합의 월 비용:

```
최소 구성   구독 하나                     $20
일반 구성   구독 하나 + API 약간          $30~50
적극 구성   Max + 편집기 구독             $120~140
```

## 잘못된 비교 대상

"월 $20이면 넷플릭스보다 비싸네" — 이 프레임이 판단을 망칩니다. 넷플릭스는 소비고 개발 도구는 생산 수단입니다. 비교 대상이 틀렸습니다.

**올바른 비교 대상은 당신의 시간입니다.**

## 시급으로 환산하면 계산이 끝납니다

연봉 6,000만 원인 개발자의 대략적인 시간당 가치를 봅니다.

```
6,000만 원 / 12개월 / 월 160시간 ≈ 시간당 31,000원
```

여기에 4대보험·장비·사무실 같은 회사 부담을 얹으면 실제 원가는 그보다 높습니다만, 보수적으로 3만 원으로 잡겠습니다.

이제 월 $20(약 28,000원)짜리 구독의 손익분기는 이렇습니다.

```
28,000원 / 시간당 30,000원 ≈ 0.93시간
```

**한 달에 한 시간을 아끼면 본전입니다.** 하루가 아니라 한 달입니다.

Max $200(약 28만 원)도 봅니다.

```
280,000원 / 30,000원 ≈ 9.3시간
```

**한 달에 9시간, 하루 30분 미만입니다.**

이 계산대로면 "월 $20을 쓸까 말까"는 고민할 문제가 아닙니다. 문제는 다른 데 있습니다.

## 그런데 이 계산에는 함정이 있습니다

위 계산은 **"시간을 실제로 아낀다"는 전제**에 전적으로 의존합니다. 그리고 그 전제가 의심스럽다는 증거가 있습니다.

METR의 무작위 대조 시험에서, 숙련 개발자들은 AI 도구를 썼을 때 **19% 더 느렸습니다.** 더 중요한 건 그들이 실험 후에도 **20% 빨라졌다고 믿었다**는 점입니다.

즉 "한 달에 한 시간은 확실히 아끼지"라는 당신의 확신은, 그 자체로는 증거가 아닙니다.

이게 "그러니 쓰지 마라"는 뜻은 아닙니다. **손익분기가 워낙 낮아서, 웬만큼 도움이 되기만 하면 여전히 남는 장사**입니다. 다만 $200짜리 결정은 $20짜리 결정과 다르게 다뤄야 합니다.

## 그래서 실무적인 기준

**월 $20까지: 계산할 필요 없습니다.** 손익분기가 월 1시간입니다. 도구가 조금이라도 도움이 되면 회수됩니다. 이 금액을 고민하는 시간이 더 비쌉니다.

**월 $100~200: 측정 후에 올리세요.** 손익분기가 월 5~10시간이면 여전히 낮지만, 이 구간은 "왠지 좋을 것 같아서"로 올리기 쉽습니다. 기준은 단순합니다 — **하위 플랜에서 실제로 한도에 막혀 일이 멈춘 적이 있는가.** 없다면 올릴 이유가 없습니다.

**월 $500 이상 (주로 API): 반드시 계측하세요.** 이 구간은 대개 자동화 파이프라인이 돌고 있다는 뜻이고, 그러면 비용이 조용히 증가합니다. 모델 등급, 프롬프트 캐싱, 배치 API로 절반 이하로 떨어지는 경우가 흔합니다.

## 회사가 내야 하는 이유

개인 지출로 다루면 두 가지가 생깁니다.

**1. 보안 구멍.** 개인 계정으로 회사 코드를 넣게 됩니다. 상용 플랜의 데이터 보호는 회사가 계약한 계정에만 적용됩니다.

**2. 잘못된 절약.** 월 3만 원을 아끼려고 시간당 3만 원짜리 사람이 기다립니다.

개발자에게 좋은 노트북을 사주는 논리와 정확히 같습니다. 차이가 있다면 노트북은 200만 원이고 이건 월 3만 원이라는 것뿐입니다.

## 정리

- 월 $20의 손익분기는 **월 1시간**, $200은 **월 9시간**입니다.
- 그래서 $20 구간은 계산할 필요조차 없습니다.
- 다만 "시간을 아꼈다"는 **체감은 신뢰할 수 없습니다.** 상위 플랜은 실제로 막혀본 뒤에 올리세요.
- 월 $500을 넘으면 계측이 필수입니다. 대개 절반은 줄일 수 있습니다.
- **회사가 내야 합니다.** 개인 지출로 두면 보안 문제가 따라옵니다.

여러분은 한 달에 얼마를 쓰시나요? 그리고 그건 회사 비용인가요, 개인 비용인가요?
