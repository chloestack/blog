## 한 문장으로

**GPT-6 Astra는 "대화하는 모델"보다 "컴퓨터 앞에 앉혀 두는 모델"에 가깝습니다.** OpenAI가 내세우는 축은 컴퓨터 사용, 장시간 에이전트 작업, 소프트웨어 엔지니어링, 사이버보안 네 가지입니다.

- **공개:** 2026년 9월 3일 일부 조직에 먼저 제공되고, 이후 며칠에 걸쳐 ChatGPT 유료 요금제와 API로 확대
- **API 모델 ID:** `gpt-6-astra`
- **제공 경로:** ChatGPT, Codex, OpenAI API, AWS Bedrock, Microsoft Azure

벤치마크 숫자는 뒤에서 다루고, 먼저 실제로 무엇이 바뀌었는지부터 봅니다.

## 1. 컴퓨터 사용이 주력 기능이 됐습니다

이번 발표에서 가장 앞에 나온 기능입니다. 화면을 보고, 클릭하고, 입력하는 방식으로 GUI를 직접 조작합니다. OpenAI가 예로 든 작업은 이렇습니다.

- 폼 작성, CRM 레코드 수정, 일정 정리
- 웹 리서치와 문서 초안 작성
- 데이터 분석과 차트 생성, 웹사이트 제작
- 소프트웨어 설치·테스트, 프론트엔드 QA
- **화면에 보이는 문제를 보고 트러블슈팅**

OpenAI는 Astra를 쓰면 **ChatGPT의 컴퓨터 사용이 이전보다 2배 가까이 빨라졌다**고 밝혔습니다. 발표 수치로는 OSWorld 2.0에서 72.6%로, 직전 모델 GPT-5.6 Sol의 65.7%보다 높습니다.

앞선 글에서 다룬 Aside와 문제의식이 같습니다. **API가 없는 사내 어드민이나 대시보드를 사람처럼 다룬다**는 겁니다. 차이는 모델 회사가 그 기능을 모델과 ChatGPT에 직접 넣었다는 점입니다.

## 2. Codex: 요약 대신 노트를 남깁니다

개발자에게 체감이 클 변화는 오히려 이쪽일 수 있습니다.

긴 작업에서 컨텍스트가 차면 기존 에이전트는 지난 내용을 **요약(compaction)해서 압축**합니다. 이 과정에서 요구사항의 세부 조건이나 앞서 돌린 테스트 결과가 뭉개지곤 합니다.

Astra는 Codex에서 **컨텍스트 창을 넘나들며 노트를 유지하는 실험적 방식**을 씁니다.

```
기존     [대화 1] → 요약 → [요약 + 대화 2] → 요약 → [요약의 요약 + 대화 3]
Astra    [대화 1] ─┐
         [대화 2] ─┼→ 누적 노트 + 이전 컨텍스트 검색 가능
         [대화 3] ─┘
```

이전 컨텍스트는 검색할 수 있게 남아 있어서, 앞에서 정한 요구사항이나 테스트 결과를 다시 찾아올 수 있다고 합니다. 아직 실험 기능이고, **몇 주 안에 기본값이 될 예정**이라고 합니다.

## 3. API 스펙

OpenAI API 문서 기준입니다.

| 항목 | 값 |
|---|---|
| 모델 ID | `gpt-6-astra` |
| 컨텍스트 창 | 1,050,000 토큰 |
| 최대 출력 | 128,000 토큰 |
| 입력 / 출력 모달리티 | 텍스트·이미지 / 텍스트 |
| 지식 기준일 | 2026년 4월 30일 |
| 추론 강도(reasoning effort) | `low`, `medium`, `high`, `xhigh`, `max` |
| 엔드포인트 | Chat Completions, Responses, Batch |
| 도구 | 컴퓨터 사용, 웹 검색, 파일 검색, Code Interpreter, 호스팅 셸, MCP |

추론 강도 옵션 위쪽에 `xhigh`와 `max`가 있다는 점을 봐 두세요. 뒤에 나오는 가격표와 합치면, **어려운 작업에만 올리고 기본값은 낮게 두는 설계**가 비용에 큰 차이를 냅니다.

## 4. API 가격

100만 토큰당 가격입니다.

| 구분 | 입력 | 캐시된 입력 | 출력 |
|---|---|---|---|
| 기본 | $10 | $1 | $50 |
| 272K 토큰 초과 요청 | $20 (2배) | $2 (2배) | $75 (1.5배) |
| Batch / Flex | 기본가의 50% | | |
| Fast 모드 | 기본가의 2배 (속도 최대 2배) | | |

감이 오도록 요청 한 건으로 계산해 보면(환율 1,340원/$1, VAT 별도):

```
입력 100K + 출력 5K
  = 0.1 × $10 + 0.005 × $50
  = $1.00 + $0.25 = $1.25  ≈ 1,675원

입력 300K + 출력 10K  (272K 초과 → 장문 단가)
  = 0.3 × $20 + 0.01 × $75
  = $6.00 + $0.75 = $6.75  ≈ 9,045원
```

100만 토큰 컨텍스트가 된다고 해서 매번 채워 넣으면 **요청 한 건에 만 원 단위**가 나옵니다. 저장소 전체를 매 요청마다 넣는 방식보다, 필요한 파일만 골라 넣고 고정된 앞부분은 **캐시 단가($1)**를 타도록 프롬프트 순서를 짜는 편이 낫습니다.

참고로 Fast 모드는 EU 데이터 레지던시 환경에서는 쓸 수 없다고 합니다.

## 5. ChatGPT 요금제별로 쓸 수 있는 곳

별도 구독 상품은 없고, **기존 요금제 안에 포함**됩니다. 헷갈리는 지점은 Chat에서는 이름이 **"GPT-6 Pro"**로 나온다는 점입니다. OpenAI는 이를 "GPT-6 Astra 기반"이라고 설명합니다.

| 요금제 | Chat (GPT-6 Pro) | Work · Codex |
|---|---|---|
| Free / Go | 없음 | 없음 |
| Plus | **없음** | 사용 가능 |
| Pro $100 | 주 50회 | 사용 가능 |
| Pro $200 | 주 200회 | 사용 가능 |
| Business / Enterprise | 사용 가능 (한도는 플랜·워크스페이스 설정에 따름) | 사용 가능 |

Plus 사용자라면 **일반 채팅 모델 선택 창에서는 안 보이고, Work와 Codex에서만 쓸 수 있다**는 점이 핵심입니다. 그리고 Chat 한도와 **Work·Codex가 함께 쓰는 사용량 한도는 따로 계산**됩니다. 한도를 넘으면 크레딧을 추가로 사야 하고, 크레딧을 산다고 출시 순서가 앞당겨지지는 않습니다.

## 6. 발표 벤치마크

**모두 OpenAI가 발표한 수치**입니다. 독립 검증은 아직 충분히 쌓이지 않았습니다.

| 벤치마크 | GPT-6 Astra | GPT-5.6 Sol |
|---|---|---|
| OSWorld 2.0 (컴퓨터 사용) | 72.6% | 65.7% |
| Terminal-Bench 4.0 | 57.9% | 37.3% |
| DeepSWE v1.1 | 74.1% | 72.7% |
| ExploitBench | 100% | 78.5% |
| 환각률 (낮을수록 좋음) | 4.2% | 12.2% |

눈여겨볼 곳은 오히려 격차가 **작은** 줄입니다. DeepSWE는 1.4%p 차이입니다. 실제 저장소 이슈를 푸는 코딩 작업에서는 "세대가 바뀌었다"는 표현만큼 차이가 크지 않을 수 있습니다. 반면 터미널 작업(+20.6%p)과 환각률(3분의 1 수준)은 차이가 뚜렷합니다.

## 7. 발표문이 크게 말하지 않은 것

### 사이버보안 기능은 막혀 있습니다

Astra는 OpenAI 준비성 프레임워크(Preparedness Framework)에서 **사이버보안 역량 "Critical" 등급을 받은 첫 모델**입니다. 시스템 카드는 "적절한 도구와 접근 권한이 있으면 알려지지 않은 보안 결함을 찾아낼 수 있다"고 적고 있습니다.

그래서 일반 사용자에게 제공되는 버전은 **고급 사이버보안 작업 요청을 거절**합니다. 익스플로잇 작성 같은 기능은 승인된 파트너만 쓸 수 있는 Daybreak 프로그램 안에서만 열립니다. 보안 쪽 업무에 쓰려던 분이라면 기대치를 조정해야 합니다.

출시 시점도 이 맥락에 있습니다. 7월 Hugging Face 사고 이후 안전장치를 더 넣느라 출시가 늦춰졌습니다.

### 추론 과정을 들여다보기가 어려워졌습니다

개인적으로는 이 부분이 가장 중요하다고 봅니다. 시스템 카드에 이런 문장이 있습니다.

> GPT-6 Astra는 이전 모델보다 chain-of-thought 모니터링 가능성이 **상당히 감소**했습니다.

Astra는 추론을 언어 토큰으로 풀어 쓰지 않고 내부에서 반복 연산하는 구조를 쓰는 것으로 알려져 있습니다. OpenAI 수석 과학자 Jakub Pachocki도 "더 유능한 모델은 더 적은 언어 토큰으로, 혹은 언어 토큰 없이 어려운 작업을 수행할 수 있다"며 모니터링이 어려워지고 있다고 인정했습니다.

에이전트를 운영하는 입장에서 뜻하는 바는 단순합니다. **"모델이 왜 그렇게 했는지"를 추론 로그로 사후 확인하는 방식에 덜 기댈 수 있습니다.** 행동 자체, 즉 어떤 도구를 어떤 인자로 불렀는지를 기록하고 제한하는 쪽이 더 중요해집니다.

### 프롬프트 인젝션은 줄었지만 0은 아닙니다

시스템 카드 기준 간접 프롬프트 인젝션 방어율은 **99.79%**입니다. 높은 숫자지만, 뒤집으면 **대략 500번에 한 번꼴로 뚫린다**는 뜻입니다. 컴퓨터 사용 에이전트는 신뢰할 수 없는 웹페이지 내용을 계속 읽습니다. 로그인된 세션으로 결제·삭제·발송 같은 작업을 맡긴다면 **사람 확인 단계는 여전히 필요합니다.**

## 정리

- **핵심은 컴퓨터 사용과 장시간 에이전트 작업**입니다. ChatGPT의 컴퓨터 사용 속도는 2배 가까이 빨라졌습니다.
- **Codex의 노트 방식 컨텍스트 관리**가 긴 작업에서 체감될 변화입니다. 아직 실험 기능입니다.
- API는 **입력 $10 / 출력 $50**이고, 272K 토큰을 넘으면 단가가 오릅니다. 100만 토큰 컨텍스트를 매번 채우는 설계는 비쌉니다.
- **Plus는 Work·Codex에서만** 쓸 수 있고, Chat의 "GPT-6 Pro"는 Pro·Business·Enterprise 전용입니다.
- 코딩 벤치마크 격차는 생각보다 작고, 사이버보안 기능은 막혀 있으며, **추론 과정의 투명성은 오히려 낮아졌습니다.**
